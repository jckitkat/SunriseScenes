What opening a mission does

Drawn here — saved from this app before. Opens exactly as it was left.

Campaign script — hand-written with lib.campaign, like the Red War drafts. It is read into the canvas; anything that could not be carried over is listed for you.

Freeroam script — an open-world destination written with lib.freeroam. Its zones, events and Lost Sectors are read from content.lua into the canvas.

Lua script — hand-written in a shape the canvas cannot draw (social spaces, the raid, scripts coded straight against the API). Every Lua file in its folder opens in a text editor with syntax checks.

Shared Lua — a folder of helpers other scripts load, such as lib. Opens in the text editor.

No script yet — an activity from the SDK with nothing written. Opens an empty canvas.

Opening a mission also loads the keys of its scenario's generated SDK module, ready on the Inputs screen.

Saving

The save button in the top bar (Save to Sunrise, or Save script for a plain folder) writes <name>/<name>.lua and, for a drawing, <name>.scene.json beside it. The first time it replaces a hand-written script, the old one is kept as <name>.lua.bak.

The Sunrise launcher updates the scripts folder and may put its own copies back. Keep your own copy of anything you care about (Save scene in the top bar).
